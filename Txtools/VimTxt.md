## Insert multiple lines
- Ctrl + v & seleccione lo q quiera alterar
- Shift + i  
- Esc
Also note that pressing . after a visual block operation will repeat that operation where the cursor is!

## Macros
- q + letra q uno quiera -> init grabació
- q -> deja de grabar
- @ + letra -> init macro, o @@
- N° + @ + letra -> ejecuta n veces la macro guardad en la letras especificada
- :registers o : reg -> muestra registros
